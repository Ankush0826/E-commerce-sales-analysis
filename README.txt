# 🛒 E-Commerce Sales Analysis using SQL & Python

> A complete end-to-end data analytics project demonstrating SQL, Python, exploratory data analysis (EDA), and business insight generation using a real-world e-commerce dataset.

---

## 📖 Overview

This project focuses on analyzing an E-Commerce dataset using **MySQL** and **Python** to uncover meaningful business insights. It demonstrates a complete analytics workflow—from importing raw data into a relational database to performing advanced SQL analysis and visualizing results with Python.

The project is designed to showcase practical data analytics skills commonly required in Data Analyst roles.

---

## 🎯 Project Objectives

* Analyze customer purchasing behavior.
* Evaluate sales performance and revenue trends.
* Identify top-performing products and customers.
* Study payment patterns and order distribution.
* Solve business problems using SQL queries.
* Generate actionable insights for decision-making.

## 🔍 Business Problems Solved

The analysis includes both **Basic** and **Advanced SQL** questions, including topics such as:

* Installment payment percentage
* Customer segmentation

### Advanced Analysis

* Moving Average Analysis

* Year-over-Year (YoY) Growth

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Ankush0826/E-commerce-sales-analysis.git
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Import the dataset into MySQL, update the database connection in the notebook, and run all notebook cells.
