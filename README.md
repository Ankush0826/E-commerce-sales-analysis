# E-commerce Sales Analysis using SQL + Python

## 📌 Project Overview
This project analyzes an E-commerce sales dataset using SQL and Python to discover business insights, customer behavior, and sales trends.

## 🛠️ Technologies Used
- Python
- SQL (MySQL)
- Pandas
- Matplotlib
- Jupyter Notebook

## 📂 Files
- sql+python_ecommerce.ipynb - Main project notebook
- README.md - Project documentation
- requirements.txt - Required Python libraries

## 📊 Analysis Performed
- Customer Analysis
- Sales Analysis
- Product Performance
- City-wise Customer Distribution
- Order Analysis
- Revenue Insights

## 📈 Key Insights
- Identified top-performing products.
- Analyzed customer distribution by city.
- Found sales trends using SQL queries.
- Visualized data using Python charts.

## 🚀 How to Run
1. Clone the repository.
2. Install required libraries:
   ```
   pip install -r requirements.txt
   ```
3. Open `sql+python_ecommerce.ipynb` in Jupyter Notebook.
4. Update your MySQL database credentials if required.
5. Run all notebook cells.
